# 嘟囔 v2 · 学习页（/learn）设计方向

学习页是全站最重要的一页：学生在这里听讲、提问、谈判、交方案、看反馈、复练。
首页的核心承诺是“和陈老师面对面”（首屏视频窗 + “和陈老师面对面”通话弹窗），学习页要接住这份承诺。

## 三个方向

### A. 视频通话（选定）
把整节课做成一次和陈老师的视频通话。
- 左侧约 60% 是通话大窗：陈老师（口型、眨眼帧来自仓库贴片），字幕压在画面上；底栏是像素按钮“打断 / 暂停 / 静音 / 结束”和“倾听 / 思考 / 讲话”状态灯。
- 情景磋商时，Markus Weber 的画中画从右下角滑入；谁在说话谁占大画面（点画中画也能换）。
- 右侧是可拖动、可最小化的窗口栈：任务（橙）、对话（紫，老师回答以中文打字气泡出现）、出处（绿）；最小化进底部 Dock。
- 进度用首页“四个场景”的文件夹标签：认识任务 → 概念讲解 → 情景练习 → 反馈 → 复练 → 完成，切换时像素淡入。
- 输入栏在通话窗下面，占位符打字轮播示例问题，建议问题是像素芯片。
- 提交方案后，反馈窗从底部升起，关键数字用首页事实条的大字；每个没达到的地方都有一键“练这一项 / 再谈一次”。
- 手机：通话窗吸顶约 1/3 屏，下面“对话 / 任务 / 出处”标签（出处是底部抽屉），输入栏固定在底部，建议问题横向滑动。

### B. 课桌与讲义
像纸质讲义：左边一摞“讲义卡”（知识卡、案例、方案表），右边是老师批注栏，数字人缩成角落小窗。
优点是适合打印和复习；缺点是“面对面”感弱，和首页的通话承诺断开，谈判场景像填表。

### C. 复古桌面
整页是一张复古操作系统桌面：图标双击打开“陈老师.exe”“买家.exe”“方案.doc”，所有内容都是自由窗口。
最贴首页的窗口语言、最好玩；但学生第一次进来不知道先点哪里，手机上无法成立，课堂投屏时也容易乱。

## 为什么选 A
1. 和首页一脉相承：首页最后一步就是“和陈老师面对面 → 开始上课”，进来就是同一通电话，不需要重新理解界面。
2. 主次清楚：画面里的人永远是主角，任务窗口告诉你现在该做什么，对话和出处随时可查——吸收了 C 的窗口玩法，但不让学生迷路。
3. 磋商最像真的：三方通话 + 画中画，买家开口时大画面切给他，比 B 的表格更有临场感。
4. 手机成立：通话吸顶 + 标签切换是视频通话类应用的通用形态。

## 保留的功能与接口（无后端改动）
讲解（`explain`）、换个例子（`again`）、提问（`ask`）、出处抽屉（`[F-…]` → 上标 `[n]`，不显示内部编号）、
开始磋商（`startPractice`）、买家对话（`negotiate`）、提交方案（`final-offer`）与表达反馈轮询（`report`）、
针对复练（`retry` + `retry/question` + `retry/answer`）、重新谈一次（`restartPractice`）、学习报告、
声音（服务端语音或浏览器兜底，静音开关）、形象状态（倾听/思考/讲话/出错）、暂停/继续、结束学习、`?start=1` 自动开课。

## 修掉的问题
- 回答里的原始出处编号（如 `[F-QUOTE-01]`）→ 可点的上标 `[1] [2]`，与“出处”窗口同一编号。
- 粉色禁用按钮看不清 → 禁用态统一为米灰底 + 弱化字 + 虚线边（≥ 4.5:1）。
- 浏览器原生英文校验气泡 → 表单 `novalidate`，用中文提示。
- 收到 `done` 后立即释放“生成中”状态：后续操作不会再去中止一条已经完成的回答。
