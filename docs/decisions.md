# 决策记录

- **新建独立工程**（2026-10-17）：旧 Mori 是品牌展示任务，课程功能放在新仓库 `human`，不改旧项目。复用其 MoriRig 角色骨架与 base.webp 素材（同一用户的 IP），去掉睡眠动作，买家角色用色相变换+角色徽标区分。
- **栈**：Vue 3.5 + Vite 7 + TypeScript 5.9（vue-tsc 3 与 TS7 不兼容，固定 ~5.9.3）；Fastify 5；node:test + tsx。
- **模型**：DeepSeek `deepseek-flash`，关闭 thinking（实测首字约 1.1 s，开启时约 1.4 s 且产生推理 token）。适配器为 OpenAI 兼容，可换服务。
- **语音**：服务端 edge-tts（中文神经语音，MP3）+ 浏览器 SpeechSynthesis 兜底；不先接收费 TTS。逐句合成、预取下一句；嘴型来自 WebAudio 实时音量；“讲话中”只由 audio playing/ended/pause/error 事件驱动。
- **检索**：几十条片段，用中文二元组 + 同义词扩展的本地打分，不引入向量库；追问时与上一问拼接再检索。引用编号必须在本次检索集合内，否则删除。
- **买家约束**：隐藏阈值只在服务端代码比较，模型只拿到 acceptable/needs_change/unknown 标签；买家回复整段校验（阈值数字、自称老师）后才下发，违规重生一次，仍违规用规则化澄清句并标注“（规则化澄清）”。
- **反馈**：客观层完全由代码算；表达建议由模型给 JSON，服务器逐条核对 turnId 与原话子串，不符即“未观察到”；无对话直接“证据不足”；不输出综合分。
- **复练**：参数与答案在服务端生成；题干先下发，提交后才返回答案。按实际错误选题型（把加成率当毛利率/算错/未填 → 毛利题；卖方条件不满足 → 条件检查题；都对 → 巩固题）。
- **会话**：匿名、内存、HttpOnly cookie 归属；每会话 1 个生成、全局 2 个、30 s 超时、1500 字。
- **部署**：Node 进程同时提供 SPA 与 /human/api，nginx 仅反代 /human/；不动根站与 /mori。
