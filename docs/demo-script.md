# 现场演示脚本（约 4 分钟，演示模式仍走真实链路）

| 时间 | 操作 | 讲什么 / 让评委看见 |
|---|---|---|
| 0:00–0:25 | 打开 pkusi.com/human，指出“服务状态（实时探测）” | 学生的难点不是背公式，而是解释报价与条件；页面显示模型与语音的真实探测时间 |
| 0:25–1:10 | 开始学习 → 开始讲解 → “请 Mori 讲解”毛利卡；讲到一半点“停止讲话”；再点“换个例子” | 真实声音、角色只在播放时张嘴；停止只停声音、文字保留；例子数字每次不同且由系统算好 |
| 1:10–1:40 | 请评委现场出一个问题（未预设），打开“出处”；再问一个资料外的问题（如汇率） | 回答带可打开的资料片段；资料外明确“材料不足” |
| 1:40–2:30 | 开始买方谈判：报 13.5 美元、30%、20 天；买家嫌贵；解释成本并让价到 12.5 | 角色切换、买家不泄露底线；聊天说成交不算 |
| 2:30–3:10 | 提交 12.5 / 30% / 20 天，“我算的毛利率”故意填 25 | 客观核算 20.00%（加成率 25%），指出用错分母；表达建议引用刚才的原话和轮次 |
| 3:10–3:40 | 练我没掌握的部分 → 作答 → 打印报告 | 复练针对刚才的错误；报告来自本次会话 |
| 3:40–4:00 | 说明自研部分与依赖、换课方式 | 见说明书第 3–5 节；未做真实试用，不展示虚构数据 |
